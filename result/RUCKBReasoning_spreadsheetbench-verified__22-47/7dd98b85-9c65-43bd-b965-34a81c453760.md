## 4. Root cause
Misread of the implicit output convention. The instruction says "sort data in
column B" and lists `answer_position F2:H20`, but does not explicitly say
"renumber the ITEM column starting at 1." The answer file resequences F as
1..N. The agent never inspected an example/answer file (none was provided to
it) and assumed the F column should mirror source A. It also declared
task_complete after a single end-to-end run without sanity-checking F values
against a plausible "ITEM column resequenced" convention. Not a hallucination,
not a timeout, not context exhaustion — a misinterpretation the agent could
have caught with one extra reasoning step ("the F column is conceptually a
new ITEM index for the deduplicated/sorted output").
