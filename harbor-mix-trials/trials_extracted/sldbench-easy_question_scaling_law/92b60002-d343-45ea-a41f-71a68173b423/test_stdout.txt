# Scaling Law Discovery Report

## Overview

This analysis discovered the mathematical relationship governing model parallelism scaling for language model evaluation across multiple benchmark groups.

## The Discovered Law

The scaling law follows a **log-linear form**:

```
brier_score = a + b × log(flops)
```

Where:
- `flops` represents the computational cost (floating point operations) during model training
- `a` and `b` are group-specific coefficients
- `brier_score` is the negative Brier score (lower magnitude = better calibration)

## Methodology

### Data Exploration
The dataset contains 389 evaluation points across 9 benchmark groups:
- abstract_narrative_understanding (32 points)
- analogical_similarity (47 points)
- arc (54 points)
- arithmetic (44 points)
- conceptual_combinations (31 points)
- hellaswag (54 points)
- hindu_knowledge (19 points)
- mmlu (32 points)
- parsinlu_qa_mc (54 points)

### Candidate Models Tested

Several functional forms were evaluated:

1. **Linear**: `brier = a + b × flops`
2. **Log-linear**: `brier = a + b × log(flops)` ✓ (Best overall fit)
3. **Inverse**: `brier = a + b / flops`
4. **Square root inverse**: `brier = a + b / sqrt(flops)`
5. **Power law**: `brier = a + b × flops^c`
6. **Hyperbolic decay**: `brier = a - b / (1 + flops)`
7. **Exponential decay**: `brier = a + b × exp(-c × flops)`

### Selection Criterion

The log-linear form was selected because:
- It provides a good balance between simplicity and explanatory power
- It captures the diminishing returns pattern common in scaling laws
- It has reasonable MSE across most groups
- It follows established scaling law theory (power-law relationships manifest as linear in log-space)

## Interpretation

- **Parameter `a`** represents the asymptotic (limiting) Brier score as flops approaches infinity. Most groups have negative `a` values, indicating better calibration (more negative Brier scores) at higher compute.

- **Parameter `b`** controls how quickly the Brier score changes with computational scale:
  - Positive `b` (most groups): Brier score magnitude decreases (worsens) with more compute
  - Negative `b` (hindu_knowledge, mmlu): Brier score magnitude increases (improves) with more compute

## Notes

The relationship is approximately linear in log-space, which is consistent with the well-known "scaling laws" observed in neural network training, where performance improvements follow power-law relationships with model size and compute.
