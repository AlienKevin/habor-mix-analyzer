def law(input_data: list[dict[str, float]], group: str) -> list[dict[str, float]]:
    """
    Predicts output variables based on input variables according to a discovered scaling law.
    """
    import math

    # Coefficients for z = a + b*x + c*x^2, prediction brier_score = -exp(z),
    # where x = log10(flops).  The same log-quadratic form is used for every
    # group; only these constants vary by group.
    coeffs = {
        "abstract_narrative_understanding": (-0.60011246, -0.35658006, -0.11324993),
        "analogical_similarity": (-0.61932512, -0.04806554, 0.03321811),
        "arc": (-2.53938168, -1.26051706, 0.16246817),
        "arithmetic": (-1.59461166, -0.73981471, 0.41066997),
        "conceptual_combinations": (-0.90957279, -0.21889940, 0.16021581),
        "hellaswag": (-3.54065080, -2.20145368, 0.33465688),
        "hindu_knowledge": (-0.89874656, 0.07889984, 0.08600737),
        "mmlu": (-0.73895233, 0.13073536, -0.02501870),
        "parsinlu_qa_mc": (-0.85104339, -0.21324601, 0.12618446),
    }
    if group in coeffs:
        a, b, c = coeffs[group]
    else:
        # Conservative fallback: mean of fitted group coefficients.
        vals = list(coeffs.values())
        a = sum(v[0] for v in vals) / len(vals)
        b = sum(v[1] for v in vals) / len(vals)
        c = sum(v[2] for v in vals) / len(vals)

    out = []
    for row in input_data:
        # Prefer the exact variable supplied in the dataset.
        if "log_flops" in row and row["log_flops"] is not None:
            x = float(row["log_flops"])
            output_name = "brier_score"
        elif "flops" in row and row["flops"] is not None:
            f = max(float(row["flops"]), 1e-300)
            x = math.log10(f)
            output_name = "brier_score"
        else:
            # Fallback for the prompt's parallel-scaling wording.  Treat the
            # effective scale as parameters (in billions, if raw parameter
            # counts are supplied) times parallel_size.
            n = float(row.get("num_params", row.get("params", 1.0)))
            p = float(row.get("parallel_size", row.get("parallelism", 1.0)))
            if n > 1e6:
                n = n / 1e9
            f = max(n * max(p, 1e-300), 1e-300)
            x = math.log10(f)
            output_name = "loss"

        z = a + b * x + c * x * x
        # Avoid numerical overflow on extreme extrapolations.
        z = min(50.0, max(-50.0, z))
        mag = math.exp(z)

        if output_name == "brier_score":
            pred = -mag
            # The observed response is a negative score bounded above by zero;
            # this clip only affects far extrapolations.
            if pred > -1e-12:
                pred = -1e-12
            if pred < -1.0:
                pred = -1.0
            out.append({"brier_score": float(pred)})
        else:
            out.append({"loss": float(mag)})

    return out

# Discovered scaling law

## Dataset actually analyzed

I loaded `/app/data` with `datasets.load_from_disk()`.  The available columns were:

- `group`
- `log_flops`
- `flops`
- `brier_score`
- `model_name`

Thus the fitted response variable in the visible data is `brier_score`, and the scale variable is `flops` (with `log_flops = log10(flops)`).

## Formula

For every experimental group I used the same functional form, with group-specific constants:

\[
\hat y_g(F) = -\exp\left(a_g + b_g x + c_g x^2\right),
\qquad x = \log_{10}(F)
\]

where:

- \(F\) is `flops`,
- \(x\) is `log_flops`,
- \(\hat y_g\) is the predicted `brier_score`,
- \(a_g,b_g,c_g\) are fitted separately for each `group`.

This is a curved power law: if \(c_g=0\), then the magnitude \(-\hat y\) is exactly a power law in compute.  The quadratic term allows the power-law exponent to change slowly with scale.

## Methodology

1. Verified that `log_flops` is exactly `log10(flops)`.
2. Examined per-group trends by sorting points by `flops`.
3. Compared several candidate laws:
   - constant per group,
   - linear, quadratic, and cubic polynomials in `log_flops`,
   - robust polynomial fits,
   - saturating/power-law forms,
   - polynomial fits to `log(-brier_score)`.
4. Used both in-sample error and a high-compute holdout test, where the largest 25% of `flops` values in each group were held out.
5. Chose the log-quadratic magnitude law because it gave low error, extrapolated better than a raw polynomial in `brier_score`, and guarantees predictions remain negative.

The selected transformed quadratic achieved approximately:

- overall training RMSE: `0.0586`
- overall training MAE: `0.0371`
- high-flops holdout RMSE: `0.0632`
- high-flops holdout MAE: `0.0384`
